# Puzzle-Parlour
A puzzle lounge in one HTML file: 3D Rubik-style cubes, slide puzzles, photo jigsaws (50/100/500 pieces), Lights Out, Hanoi, Flood and Ball Sort. A live teacher on every table shows your next move and teaches each solving method. Touch-friendly, with hints, lessons, a star shop and settings. Free, no ads, no sign-up, works offline.
